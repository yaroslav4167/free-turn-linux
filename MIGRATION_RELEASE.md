# FreeTurn Linux v2.6.6 — переход в общий репозиторий

Windows, Linux и macOS теперь выпускаются вместе:
https://github.com/yaroslav4167/free-turn-desktop

Установите это обновление обычным способом. После перезапуска откройте
настройки и проверьте обновления ещё раз: клиент предложит общий v3.0.0,
выбирая только Linux-архив нужной архитектуры и проверяя SHA-256.

Это минимальное переходное обновление поверх v2.6.5: меняется источник
будущих обновлений. Профили, настройки и установка VPN-helper сохраняются.
Серверы на VPS не изменяются. Старые релизы и теги остаются доступны.
